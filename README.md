## 🧭 How I Approach Security

<p align="center">
  <img src="https://img.shields.io/badge/01-SCOPE-8B0000?style=for-the-badge" alt="Scope" />
  <img src="https://img.shields.io/badge/02-OBSERVE-007C91?style=for-the-badge" alt="Observe" />
  <img src="https://img.shields.io/badge/03-TEST-087A45?style=for-the-badge" alt="Test" />
  <img src="https://img.shields.io/badge/04-VERIFY-6F42C1?style=for-the-badge" alt="Verify" />
  <img src="https://img.shields.io/badge/05-DOCUMENT-111111?style=for-the-badge" alt="Document" />
</p>

- **Understand the scope** before testing.
- **Question assumptions** and inspect behaviour, not just appearance.
- **Verify evidence** before drawing conclusions.
- **Explain impact clearly** and keep useful notes.
- **Respect permission and privacy** in every security exercise.
