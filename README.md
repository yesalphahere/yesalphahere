## 👋 Who I Am

Hey, I'm **Sabir Ali** — a Computer Science graduate who enjoys understanding how software, networks, and connected devices work, and how they can be made safer.

I'm building my cybersecurity skills through **hands-on web security labs, technical projects, and careful documentation**. My current practical focus is web application security, especially access control, authentication, and API behaviour. I'm also curious about network and system security, IoT/embedded devices, and AI security and privacy.

## 🧭 My Security Workflow

<p align="center">
  <img src="./assets/security-pulse.gif" width="112" alt="Animated neon shield representing responsible security testing" />
</p>

<p align="center">
  <img src="https://img.shields.io/badge/01-SCOPE-8B0000?style=for-the-badge" alt="Step 1: Scope" />
  <img src="https://img.shields.io/badge/02-OBSERVE-007C91?style=for-the-badge" alt="Step 2: Observe" />
  <img src="https://img.shields.io/badge/03-TEST-087A45?style=for-the-badge" alt="Step 3: Test" />
  <img src="https://img.shields.io/badge/04-VERIFY-4B0082?style=for-the-badge" alt="Step 4: Verify" />
  <img src="https://img.shields.io/badge/05-DOCUMENT-111111?style=for-the-badge" alt="Step 5: Document" />
</p>

- **Permission first:** practise in labs or systems I'm authorised to test.
- **Evidence over assumptions:** reproduce behaviour before drawing conclusions.
- **Impact with context:** explain what happened, why it matters, and what could be improved.
- **Keep learning:** build stronger fundamentals before claiming mastery.
